Welcome to the repository of my personal developer portfolio! This modern, dark-themed responsive website showcases my featured software development projects, technical education in Multiplatform Application Development (DAM), professional internships at Accenture, and native bilingual background.

---

## ✨ Features

- 🌓 **Modern Dark Design:** Clean UI featuring custom gradient elements, blob frames, and a floating dock navigation bar.
- 🌐 **Fully Bilingual (ES / EN):** Seamless language switching between Spanish (`indexEsp.html`) and English (`indexEn.html`).
- 📱 **100% Responsive:** Optimized for desktops, tablets, and mobile devices with fluid layout adjustments.
- 🎯 **Project Showcase:** Highlights mobile and desktop applications (Flutter/Dart, Java, MySQL, Web).
- 📜 **Interactive CV Download:** Direct PDF download integration.
- 👤 **Quick Anchor Navigation:** Smooth scrolling controls with top user-anchor link.

---

## 🛠️ Built With

- **HTML5:** Semantic markup and structure.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, glassmorphism backdrop filters, and keyframe animations.
- **FontAwesome:** Scalable vector icons.
- **FlagCDN:** High-quality SVG flag indicators.
